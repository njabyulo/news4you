# Superseded local publisher setup

Production publishing now runs in Cloudflare Workflows with a Cloudflare Cron Trigger. No Ollama or operator computer is required. Hosted Gemma edits public news/weather only. Email metadata and calendar events are displayed directly and never sent to AI.

The previous local private-content editor and watcher have been removed from the active publication path. See [live generation](live-generation.md) and the README deployment instructions.
